# Contributing

Thanks for helping with the GlassVGL samples.

- Bug reports are welcome as issues. Give your board, toolchain, LVGL version and the sample you
  built, and paste the build error or what the STATS demo screen shows.
- Pull requests that fix a sample or add one for another board or toolchain are welcome. Keep each
  one to a single sample or fix, build it with that toolchain before you send it, and add a line to
  `CHANGELOG.md`.
- Please don't post GlassVGL Edge GUI source code in issues or pull requests. It is under a paid licence.
